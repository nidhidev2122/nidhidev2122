## 🚀 Featured Projects

### ⚡ [Namma Electricity — Bengaluru Electricity Intelligence Platform](https://github.com/nidhidev2122/Namma-Electricity)

A household electricity intelligence platform designed to help people understand their electricity consumption and make informed decisions.

- 📊 Consumption trends and appliance-level usage estimates.
- 💡 Bill, tariff, and subsidy insights.
- 🧠 Personalized energy-saving recommendations.
- 🔋 Household load estimation and local outage insights.

`Energy Analytics` `Python` `React` `FastAPI` `Machine Learning`

### 🌾 [KhetX — AI-Assisted Agricultural Intelligence](https://github.com/nidhidev2122/KhetX)

An agricultural decision-support project focused on helping farmers make more informed crop-management and farming decisions.

- 🌱 Crop planning and farming action guidance.
- 🌦️ Weather-aware recommendations and risk analysis.
- 📈 Market-price comparison and profit tracking.
- 🧠 Exploring AI-assisted agricultural decision-making.

`AgriTech` `AI/ML` `Python` `FastAPI` `React`

### 🩺 [Medix — Disease Prediction Using NLP](https://github.com/nidhidev2122/Medix)

A symptom-based disease prediction project exploring natural language processing and traditional machine-learning classification.

- 🔎 Text preprocessing and TF-IDF feature extraction.
- 🤖 Classification using Naive Bayes and Logistic Regression.
- 📊 Model comparison and prediction interface.

`Python` `NLP` `Scikit-learn` `TF-IDF` `Streamlit`

### 🏠 [FIXIO — Home Services Marketplace](https://github.com/nidhidev2122/FIXIO)

A collaborative web application designed to connect users with home-service providers through a streamlined booking experience.

`HTML` `CSS` `JavaScript` `Node.js` `Express` `MongoDB`
